# LIMU 教師專用小工具 v20.4（App 16.0.4）

## 部署

請保留原有目錄結構，將這個資料夾內的所有檔案一起上傳到網站根目錄。不要只更新單一檔案；`index.html`、`sw.js` 與 `version.json` 必須來自同一個 v20.4 部署包，PWA 圖示、本機 ReactDOM 與原始美術素材也請一併保留。

部署後第一次開啟時請保持網路連線。v20.4 會繞過 iPhone 的舊 HTTP 快取，核對 `index.html`、`sw.js` 與 `version.json` 的建置識別；完整下載後自動啟用並重新載入。畫面左上版本應顯示 `v16.0.4`。若網站仍在分批更新而造成混版，App 會停止安裝並提示重新上傳完整部署包，不會把舊頁面重新寫回新版快取。

`firestore.rules` 是 Firebase Firestore 規則參考檔，不需放進網頁主機；只有在 Firebase 規則尚未部署時才需要到 Firebase Console 更新。

## v20.4 圖片可見度與 iPhone 換版修正

- 修正實機仍顯示 `v16.0.2` 的主因：Service Worker 註冊改為 `updateViaCache: none`，安裝後自動接管並清除 v20.2／v20.3 舊 App Shell。
- 導覽請求強制先讀網路且核對建置識別；伺服器若短暫回傳舊 HTML，會退回已驗證的 v20.4，不再降版。
- 修正一處慕夏星期列多層背景的 CSS 分隔符錯誤。

- 空白月份的直式鳶尾在 Mucha 與 Nebula 均會顯示，有資料後仍由內容自然取代。
- 所有裝飾維持 `pointer-events: none`；固定班級列、月份切換、日期格、同步狀態、彈窗與底部導覽的觸控層級不變。
- Firebase、班級 ID、每日資料、封存與 schema v6 完全不變。

## v19 延續：固定定位、效能與美術精緻化

### 固定式班級定位

- 所有主要頁面固定顯示精簡班級定位列，包含學年度、班級、資料天數與同步狀態。
- 手機常駐列高度約 42～48px；原本月曆上方的大型定位卡已移除，首屏可用空間不會反而變少。
- 點擊定位列會展開完整資訊：本機／雲端天數、日期範圍、待同步、衝突、學年度範圍外資料、第一筆與最近一筆。
- 展開面板可直接切換班級；沒有把刪除功能放入切換入口，避免誤觸。
- 開啟彈窗或底部面板時，定位列會位於遮罩下方，不會蓋住操作。
- 快速切換班級時加入請求序號，舊班級較晚完成的定位結果不會覆蓋目前班級。

### 效能提升

- 全域搜尋先排除非作業／輔導資料鍵，再以有限併發讀取，降低無效工作。
- 大量歷年資料搜尋每處理 40 筆會主動讓出主執行緒，iPhone 捲動與按鈕回應不會長時間凍結。
- 搜尋加入請求序號；較早的慢搜尋不會覆蓋後來輸入的新關鍵字。
- 月份紀錄摘要改為單次記憶化計算，空白月份提示、清單與統計共用同一結果。
- 月份下方的摘要、出勤、抵免與回條區塊使用延遲繪製及繪製隔離，螢幕外內容不搶首屏資源。
- App 切到背景時暫停裝飾動畫，回到前景後再恢復。
- Google 字型改為非阻塞載入，並預先連線 Firebase 靜態資源來源，減少第一次開啟的等待。

### 美術與質感精緻化

- 預設主題改為分層藍灰介面：深色品牌標題、霧面背景、清楚的白色內容卡與一致陰影。
- 月曆改用更乾淨的白色格面、柔和完成／缺交色階、今日內框與較清楚的星期列。
- 班級定位列使用精簡玻璃質感，但在手機上限制模糊範圍，兼顧質感與效能。
- 單日工具重新分層：日常保留「同步、週計畫、復原、重做」；技術診斷與獎卡資料掃描收入「更多」。
- 底部導覽、面板圓角、按鈕觸控回饋與卡片邊框統一；NERV 與 Nebula 主題保留各自識別，不會被預設主題覆蓋。
- PWA 啟動畫面背景與瀏覽器主題色同步更新為新版深藍／霧藍色系。

資料格式仍為 schema v6；v20 不搬移、不刪除、不重命名既有 Firebase、班級 ID、每日資料或封存。

### 沿用 v15＋v16 合併升級

- 所有歷年統計、學期統計、學生分析、公開行事曆與資料定位統一使用完整學年度：例如 114 學年度＝西元 2025/08/01～2026/07/31，不再漏掉隔年 1～7 月。
- 學年度欄位可輸入民國 3 位數或西元 4 位數；輸入 `114` 會自動正規化成西元起始年 `2025`。
- 更正學年度前會顯示安全預覽：班級 ID 是否保留、現有資料日期範圍、範圍內／範圍外天數；更正只修改設定，不搬動或刪除原資料。
- 更正後會自動跳到新學年度範圍內最接近今天的既有紀錄。已實測「2026 改成 114／2025」後仍定位到 2026 年 7 月資料。
- 主月曆新增「班級資料定位器」，顯示本機／雲端天數、第一筆與最後一筆日期、待同步、衝突、最近同步時間及學年度範圍外資料。
- 每個「歷年檔案」班級標題也有獨立資料定位資訊及「跳到第一筆／最後一筆」。
- 停在空白月份時，App 會主動告知其他月份仍有資料，並提供「立即查看最近資料」，避免誤以為資料遺失。
- 新增「今日工作台」：集中顯示今日作業完成度、待確認座號、出勤、行事曆、未來 7 天重要事件、週計畫與輔導筆數。

- 新增全域搜尋，可跨日期與裝置內歷年班級搜尋作業、缺交座號、出勤、日輔導、正式輔導、週計畫及公開行事曆。
- 全域搜尋同時掃描 IndexedDB 與 localStorage 備援；即使其中一種儲存暫時不可用，仍會盡量找出既有紀錄。
- 標題列與設定預覽改用「114 學年度」等明確文字，並同時顯示對應西元日期範圍。

### 沿用並保留的資料安全功能

- 封存還原只處理使用者選定的目標班級；還原「五年壬班」不會再建立封存檔內的「六壬」或「六年壬班」。
- 完整刪除入口全部集中到「歷年檔案」的每個班級標題，班級切換與設定頁不再提供資料刪除入口。
- 完整刪除會處理該班的每日作業、出勤、回條、每日輔導、正式輔導、週計畫、分組、幹部、行事曆、學校公開事件、封存版本及同步殘留。
- 刪除後會記錄班級墓碑；舊封存、舊設定或另一台裝置同步時，都不會讓已刪班級自動復活。
- 登入 Firebase 時必須在線才能完整刪除；若雲端刪除失敗，App 會保留班級入口供重試，不會假裝成功。
- 班級設定採固定「年／班」雙欄格式，舊有「六年壬班」會自動拆為「六」與「壬」。
- 更新或切換班級時，若今天位於該學年度範圍，月曆會停在今天；月曆列也新增「今天」按鈕。
- 新增完全免費的公開學校行事曆：不使用 Cloud Functions、不需要 Blaze、不嵌入 Google API 金鑰，也不要求私人 Google 行事曆授權。
- 可輸入學校網站自動偵測公開 Google Calendar、`.ics`、CSV、JSON 與網頁 JSON-LD 事件。
- 已內建大甲國小目前公開校務行事曆的免費辨識備援；即使首頁本身不允許跨網域讀取，仍會嘗試讀取其公開 Google 行事曆。
- 若學校網站禁止跨網域讀取，畫面會明確要求改貼公開行事曆直接連結，或匯入已下載的 `.ics`／CSV／JSON；不會使用第三方代理。
- 所有外部事件先進入勾選清單，支援全選、全不選與逐筆決定，確認後才加入目前班級。
- 公開事件與既有手動行事曆分開保存；不改寫舊資料，不影響每日作業、出勤、輔導或週計畫。
- 當日作業紀錄上方可展開事件完整內容、標記 `★重要`，並以「只留重要」一鍵隱藏一般事件。
- 刪除公開事件後會記入「已排除」，下一次匯入不會自動加回；可在匯入畫面恢復誤刪事件。
- 支援同一天多筆公開事件、處室／來源標示、重複行程展開與跨日事件。
- 公開事件按班級隔離，並沿用既有 Firestore revision 衝突保護與自動重試；Firebase 專案和規則不需更換。
- 完整封存與加密備份會包含公開事件、重要標記、來源設定與排除清單。
- 學年度轉換目標固定為「目前班級學年度＋1」，116、117、118 等後續年度可持續使用。
- 同一來源班級不能重複建立相同學年度；同校、同班名、同學年度也會阻止重複。
- 手動新增班級若撞到既有資料，會直接切換到原班級，不再產生重複副本。
- 上下學期開始日與匯入行事曆會核對學年度範圍，避免日期誤填到前一年或後一年。
- 轉換紀錄保留來源學年度與轉換時間，方便日後確認資料來源。
- 班級設定、組別版本、幹部及行事曆全部加入 revision 交易保護，跨裝置衝突不再由最後寫入者直接覆蓋。
- 設定衝突整合至既有「同步衝突」中心，可選擇使用此裝置或雲端版本。
- Firebase 暫時失敗時，會依 5 秒、15 秒、45 秒、2 分鐘、5 分鐘延遲自動重試；衝突資料不會無限重送。
- 設定頁顯示 App 版本、建置日期、快取版本與資料格式版本。
- 通用學年度轉換助手：先檢查舊學年完整封存，再建立下一學年度班級、設定開學日並匯入新行事曆。
- 轉換時可複製組別名稱與幹部職稱，但不會複製學生座號或幹部人選。
- 行事曆改為按班級獨立保存，並保留舊版全域行事曆的自動遷移相容性。
- Service Worker 只會啟用通過三檔建置識別核對的完整版本；v20.4 下載完成後自動切換，避免 iPhone 長期停在舊 App Shell。
- 週計畫與輔導紀錄可離線新增、編輯與刪除，重新連線後補同步。
- 每日資料、週計畫與正式輔導都使用交易式版本檢查；偵測到另一台裝置已修改時不直接覆蓋。
- 功能選單新增「同步衝突」中心，可選擇本機、雲端、合併週計畫或讓兩筆輔導都保留。
- 完整備份包含每日紀錄、日輔導、週計畫、正式輔導、分組、幹部、設定與行事曆，並附 SHA-256 校驗。
- 下載備份時可選擇 AES-256-GCM 密碼保護；仍相容一般 JSON 與舊版備份。

- 本機網站儲存空間超過 80% 時才顯示提醒，平常不增加常駐儀表板。

- 實際顯示用的鳶尾 WebP 內嵌於 `index.html`，避免部署路徑漏檔；透明 PNG／WebP 原圖仍保留於 `assets` 供日後編修。

## 建議操作

重要學期資料請定期到「學年歷史檔案室」下載密碼保護備份，並把密碼存放在可信任的密碼管理工具。密碼遺失後無法解密。第一次從其他裝置匯入後，請確認班級、週計畫與輔導紀錄皆可見。

若要清除目前空白的「六壬」與「六年壬班」，請在登入且有網路時進入「歷年檔案」，分別按兩個班級標題內的「完整刪除」，再依提示輸入完全相同的班名。兩個班級是不同資料範圍，必須各操作一次；「五年壬班」不會受到影響。

公開行事曆單次來源上限為 5 MB、最多保留 3,000 筆事件。學校網站只能在對方允許瀏覽器跨網域讀取時自動取得；遇到限制時，下載公開檔案再匯入是完全免費且最穩定的備援方式。
