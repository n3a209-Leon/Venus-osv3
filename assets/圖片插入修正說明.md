# LIMU v20.3 圖片插入修正

## 找到的問題

v20.2 的裝飾圖使用 `./assets/*.webp` 相對路徑。只要部署平台沒有完整保留 `assets` 目錄、漏傳一張圖片、改變檔名大小寫，或舊 Service Worker 仍控制頁面，就會產生破圖或繼續顯示舊版。

同時，v20.2 的 Service Worker 使用 `cache.addAll()` 強制下載全部裝飾圖；其中任何一張取得失敗，都會讓整個新版安裝中止。

## 修正方式

- 11 張實際顯示用的慕夏／藍紫鳶尾 WebP 直接內嵌在 `index.html`。
- CSS 與 React 共用同一份內嵌圖片，不重複依賴外部路徑。
- Service Worker 的必要快取清單移除裝飾素材，避免單張圖片拖垮整版更新。
- 原始透明 PNG 與 WebP 繼續保留在 `assets`，方便未來再編修。
- 外框、卡片框、角花與空白裝飾提高辨識度；所有裝飾仍為 `pointer-events:none`，且位於內容底層或安全邊界。
- 固定班級列、同步狀態、月份切換、日期格、彈窗與底部導覽仍在裝飾上層。

## 部署必要檔案

更新時至少同步上傳：

- `index.html`
- `sw.js`
- `version.json`

建議仍直接上傳完整 v20.3 部署包，以保留 PWA 圖示、本機 ReactDOM 與原始美術素材。
